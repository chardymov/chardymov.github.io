# Театр Вентилятор — сайт

Статический сайт: два раздела (театр и студия актёрского мастерства), данные редактируются через Google-таблицу.
Работает без сервера и без сборки — достаточно открыть `index.html`.

---


## 2. Как запустить

**Просто посмотреть:** откройте `index.html` двойным кликом. Всё работает, кроме
загрузки из Google-таблицы (браузер блокирует запросы с `file://`).

**Правильный способ** — локальный сервер. В терминале, находясь в папке `site`:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`.

**Опубликовать в интернете** (бесплатно):

- **GitHub Pages** — залейте папку в репозиторий, в настройках включите Pages.
- **Netlify** — перетащите папку `site` на [app.netlify.com/drop](https://app.netlify.com/drop).

## 3. Google-таблица как админка

### Шаг 1. Создайте таблицу

Создайте новую Google-таблицу. Сделайте в ней **девять листов** с такими названиями
(регистр важен):

`settings`, `shows`, `sessions`, `actors`, `trainers`, `courses`, `program`, `starts`, `schedule`

В каждый лист импортируйте одноимённый файл из папки `sheets/`
(*Файл → Импортировать → Загрузить → выбрать CSV → «Вставить на текущий лист»*).
Там уже лежат все демо-данные — будет с чего начать.

### Шаг 2. Откройте доступ

*Настройки доступа → Доступ по ссылке → «Читатель»*.
Без этого сайт таблицу не увидит.

### Шаг 3. Пропишите ID

Из адресной строки таблицы скопируйте ID:

```
docs.google.com/spreadsheets/d/1AbCdEfGh...ID_ЗДЕСЬ.../edit
```

и вставьте его в `assets/js/config.js`:

```js
SHEET_ID: "1AbCdEfGh...",
```

Готово. Теперь сайт берёт весь контент из таблицы, а `assets/data/content.js`
остаётся запасным вариантом на случай, если таблица недоступна.

### Правила заполнения ячеек

| Что | Как писать |
|---|---|
| Несколько абзацев в одной ячейке | Разделяйте вертикальной чертой: `Первый абзац \| Второй абзац` |
| Список id (актёры в спектакле, фото в галерее) | Через запятую: `anna-poletaeva, pavel-demin` |
| Титры спектакля | `Режиссёр::Иванов \| Свет::Петров` |
| Фотография | Имя файла без суффикса размера: `hades-blue-table`. Можно и полную ссылку `https://...` |
| Дата и время сеанса | `2026-10-03T19:00` |
| Занятые места | `А3,А4,Б5,В1` — эти места сайт закрасит на схеме зала |

Данные кэшируются на 10 минут (настраивается в `config.js`). Чтобы увидеть правку
сразу — обновите страницу с Ctrl+Shift+R.

## 4. Листы таблицы

**settings** — `key`, `value`. Адрес, телефоны, соцсети, подсказки как добраться,
текст обращения режиссёра (абзацы через `|`), цифры для блока статистики.

**shows** — спектакли. `status`: `active` (в афише) или `soon` (готовится премьера).

**sessions** — сеансы. Три цены по зонам зала: `price_a` (ряды А–Б), `price_b` (В–Г),
`price_c` (Д–Е). `sold` — занятые места. `timepad_id` — id события на Timepad (см. ниже).

**actors** — труппа. `trainers` — тот же формат, для тренеров, которые не играют
в спектаклях; сайт объединяет оба листа.

**courses** — пять курсов. `trainer` — id человека из `actors`/`trainers`.

**program** — программа занятий: `course`, `module`, `title`, `hours`, `description`.
Одна строка = один модуль.

**starts** — ближайшие наборы. `left` — сколько мест осталось, `status`: `open` или `soon`.

**schedule** — расписание текущих групп: `day`, `time`, `course`, `title`.

## 5. Билеты

Схема зала — **малый зал, 60 мест**: ряды А–Е по 10 мест, проход между 5-м и 6-м.
Зоны и цены:

| Ряды | Зона | Цена из колонки |
|---|---|---|
| А, Б | Первые ряды | `price_a` |
| В, Г | Центр | `price_b` |
| Д, Е | Дальние ряды | `price_c` |

Занятость берётся из колонки `sold` листа `sessions`. Заполненность видна в афише
полоской «свободно N из 60».

### Два сценария оплаты

**1. Через Timepad** — если у сеанса заполнена колонка `timepad_id`.
Зритель выбирает места, вводит имя и телефон, нажимает «Оплатить на Timepad» —
открывается официальный виджет Timepad с оплатой картой.

Что нужно: в `config.js` укажите `TIMEPAD_ORG` (ваш поддомен `ИМЯ.timepad.ru`),
а в таблице для каждого сеанса — id события. Id виден в адресе события:
`ventilyator.timepad.ru/event/**2891234**/`.

**2. Бронь без оплаты** — если `timepad_id` пуст.
Зритель выбирает места, оставляет контакты и получает готовый текст брони,
который отправляет в телеграм одной кнопкой. В `config.js` можно задать
`BOOKING_FORM_URL` — ссылку на вашу Google-форму, тогда она откроется
автоматически (подставьте `{order}` в ссылку, чтобы туда попал текст заказа).

> Важно: сайт статический, он не хранит брони сам. Отметить проданные места
> нужно в колонке `sold` — либо руками, либо выгрузкой из Timepad.
> Если нужна автоматическая синхронизация занятости с Timepad — это следующий
> шаг, потребуется небольшой скрипт (Google Apps Script) внутри таблицы.

## 6. Фотографии

В `assets/img/` лежит 50 фотографий в трёх размерах: `-lg` (1800 px, для героев),
`-md` (900 px, карточки и галереи), `-sm` (480 px, аватарки).

Чтобы добавить новую фотографию: положите её в `assets/img/` тремя файлами
`имя-lg.jpg`, `имя-md.jpg`, `имя-sm.jpg` — и указывайте в таблице просто `имя`.
Скрипт, который это делает, лежит рядом: `tools/prep-images.py`.

Логотип — `assets/img/logo.png` (белый, с прозрачным фоном).

## 7. Что здесь демо и требует замены

Сайт заполнен правдоподобными заглушками, чтобы сразу было видно структуру.
Заменить на реальное:

- [ ] Названия и описания шести спектаклей, даты сеансов, цены
- [ ] Имена, биографии и должности актёров труппы (**фотографии настоящие, имена выдуманы; настоящая только Диана Нурмухаметова**)
- [ ] Тексты обращения режиссёра
- [ ] Телефон, почта, ссылки на Telegram и ВКонтакте
- [ ] Цены и даты наборов на курсы
- [ ] **Подсказки «как добраться»** — маршруты транспорта взяты по улице Пушкина
      в целом, время пешком от метро не проверялось. Уточните и поправьте
      в листе `settings` (`route_metro`, `route_bus`, `route_car`, `route_door`)
- [ ] Реквизиты юрлица и оферта, если будете принимать оплату

## 8. Технические мелочи

- Шрифт Inter подгружается с Google Fonts.
- Карта — виджет Яндекс.Карт по адресу из `settings.map_query`.
- Данные кэшируются в `sessionStorage` на время сессии браузера.
- Вёрстка адаптивная, проверена от 360 px.
- Сайт работает без JavaScript-сборщиков: никаких npm, node_modules и билда.
