# Мы вдвоём — портрет пары и разговоры

Сайт для проверки гипотезы: пары, которые давно вместе, снова начинают разговаривать друг с другом.
Два раздела:

1. **Портрет пары** — 32 вопроса (6 блоков + необязательный блок о сексуальности), психологический разбор отношений.
2. **Разговоры** — 12 тем для глубоких разговоров: «Откуда мы родом», «Как всё начиналось», «Мечты и „если бы“»,
   «Страхи и уязвимость», «Признание и благодарность», «Друзья, родные и границы», «Работа, амбиции, усталость»,
   «Тело, здоровье, возраст», «Дети и то, что останется после нас», «Деньги глубже», «Желание и секс — глубже» (18+),
   «Кризисы, которые мы пережили». Новые темы добавляются в `assets/topics.js`; в `soon` можно перечислить будущие
   темы — на сайте за них голосуют (событие `vote_topic`). Пара выбирает одну тему на сегодня.
   Каждый отвечает сам, а на части вопросов ещё и угадывает ответ партнёра. Итог — разбор: кто кого угадал,
   связи с портретом и прошлыми темами, план разговора на вечер и практика на неделю.

В обоих разделах на большинство вопросов можно выбрать до двух вариантов (шкалы — один).
Разбор каждой темы сквозной: оси и наблюдения считаются по всем модулям, которые пара уже прошла вдвоём.

**Кабинет пары** (`?c=<id>&t=<токен>`) — личная ссылка из писем: что пройдено, чья очередь, выбор следующей темы.

**Как работает портрет**

1. Человек отвечает на вопросы, вводит своё имя и email, имя и email партнёра.
2. Ему на почту приходят его ответы и личный портрет, партнёру — ссылка-приглашение.
3. Партнёр отвечает по ссылке → ответы сравниваются → разбор приходит обоим и сразу показывается на сайте.

Разбор: индекс согласованности, совпадения по блокам, оси (открытость, близость, планирование, традиционность,
деньги, темперамент), ключевые динамики пары («один догоняет, другой отстраняется», больные точки в споре,
языки любви и т. д.), опоры, расхождения с подсказками, портреты, «инструкция по применению» каждого
и рекомендации. Если задан ключ Anthropic API, Claude дописывает раздел «Общий взгляд на вашу пару».

## Структура

| Файл | Что внутри |
|---|---|
| `index.html`, `assets/app.js`, `assets/style.css` | Сайт (GitHub Pages) |
| `assets/questions.js` | Вопросы портрета: варианты, веса и подсказки |
| `assets/topics.js` | Темы «Разговоров»: вопросы, догадки, вопросы для разговора, практики, сквозные связи (`links`) |
| `assets/analysis.js` | Движок разбора портрета и шаблоны писем (общий для сайта и бэкенда) |
| `assets/talks.js` | Движок разбора тем: догадки, сквозные связи, план разговора, письма |
| `assets/config.js` | `API_URL` бэкенда. Пусто = демо-режим |
| `backend/Code.gs` | Бэкенд на Google Apps Script: таблица + письма + Claude |

## Демо-режим

Пока в `assets/config.js` пустой `API_URL`, сайт работает без бэкенда: пары хранятся в браузере,
а письма видны по кнопке «Демо-почта» внизу справа. Ссылку партнёра можно открыть из письма-приглашения
в той же вкладке — так проверяется весь сценарий в одном браузере.

Локально: `python3 -m http.server 8765` в корне репозитория → http://localhost:8765

## Подключение бэкенда (≈10 минут)

> Письма уходят с того Google-аккаунта, от имени которого развёрнут скрипт, и адрес отправителя видят получатели.
> Для тестов лучше завести отдельный Gmail под проект. Лимит бесплатного Gmail — около 100 писем в сутки
> (портрет = 4 письма на пару, тема = 3 письма).

1. Создайте новую Google Таблицу (например, «Мы вдвоём — ответы»).
2. В таблице: **Расширения → Apps Script**. Удалите содержимое `Code.gs` и вставьте код из `backend/Code.gs`.
3. **Project Settings (шестерёнка) → Script properties** → добавьте:
   - `SITE_URL` = `https://chardymov.github.io/`
   - `ANTHROPIC_API_KEY` = ваш ключ (необязательно, без него разбор строится только по правилам)
   - `CLAUDE_MODEL` (необязательно, по умолчанию `claude-opus-5-5`)
   - `SENDER_NAME` (необязательно, имя отправителя писем)
4. В редакторе выберите функцию `setup` и нажмите **Run** — Google попросит разрешения
   (таблица, отправка почты, внешние запросы). Появятся листы `pairs`, `talks` и `events`.
5. По желанию запустите `sendTestReport` (портрет) или `sendTestTalk` (тема) — себе на почту придёт пример разбора на случайных ответах.
6. **Deploy → New deployment → Web app**: *Execute as* — **Me**, *Who has access* — **Anyone**. Скопируйте URL (`…/exec`).
7. Вставьте URL в `assets/config.js` → `API_URL`, закоммитьте и запушьте.

После изменения `Code.gs` нужно сделать **Deploy → Manage deployments → Edit → New version**, иначе работает старая версия.

Вопросы, темы и движки разбора бэкенд загружает с сайта (`SITE_URL/assets/…`, кеш 10 минут), поэтому их правки
не требуют передеплоя скрипта. Если `eval` в Apps Script по какой-то причине недоступен, вставьте
содержимое `assets/questions.js`, `topics.js`, `analysis.js` и `talks.js` (в этом порядке) в проект Apps Script
как отдельные файлы — скрипт увидит их и не будет ничего загружать.

## Данные для анализа гипотез

- Лист `pairs`: каждая пара — имена, email, ответы портрета (JSON), время завершения, индекс, текст от Claude, UTM
  (`meta.start` — тема, с которой пара начала, если не с портрета).
- Лист `talks`: одна строка на тему пары — ответы каждого `{a: ответы, g: догадки, note: фраза партнёру}`, время завершения, текст от Claude.
- Лист `events`: воронка — `view_landing`, `start`, `block_done`, `skip_sex`, `view_details`, `submit_a`,
  `invite_open`, `submit_b`, `view_report`, `view_cabinet`, `topic_pick`, `topic_open`, `topic_start`,
  `topic_submit`, `submit_portrait`, `view_talk`, `vote_topic` (голос за тему «скоро») с идентификатором сессии и UTM-метками.

Для разных каналов давайте ссылки с метками, например `https://chardymov.github.io/?utm_source=telegram&utm_campaign=test1`.

## Приватность

Ответы, включая блок о сексуальности, хранятся в вашей Google Таблице, а при включённом Claude — отправляются в Anthropic API.
Перед отправкой пользователь подтверждает 18+ и согласие на обработку. Итоговый разбор с ответами обоих получают оба партнёра.
В сквозной разбор темы попадают только модули, которые оба партнёра уже прошли (то, что оба уже видели).
